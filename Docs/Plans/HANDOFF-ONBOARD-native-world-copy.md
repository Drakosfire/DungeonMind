# ONBOARD: isolated native World copy

Status: ACTIVE. The owner authorized a signed-out Buddy experience using the
normal product with an isolated copy of the ingested Sizzek World. This Core
slice provides the missing native operation: copy one explicitly authorized,
revision-pinned native graph and its openable text evidence into a newly
allocated, separate World. Buddy owns the guest session, stable release choice,
workspace documents, auth, reset and UI; this operation is not a public route.

Serial topology: Core copy capability first; Buddy integration depends on the
reviewed Core contract and will use the normal Graph and other product surfaces.
Base `origin/main` at `0a6cf9a9acb6ee5e47ee0bf5db06bd091afebb9f`, branch
`codex/sizzek-native-world-copy`, checkout this worktree. Existing Core PRs
#295/#296 own source-reader/PostgreSQL files and #298 owns source access/model;
this slice uses existing APIs and leases only this handoff, a new vNext copy
module and its new focused tests. No shared database, benchmark, port, provider,
production runtime, existing World or external service is leased.

The input is an explicitly authorized source space/revision and a pinned source
authority view. Preserve graph entities, assertions, aliases, temporal and
visibility metadata, and support/context evidence with verified text bytes and
spans; retain source provenance. Destination is uniquely allocated, never the
source. Detect unsupported evidence and integrity errors before publication;
never silently omit facts. The same operation inputs must replay safely, reject
mismatched bindings, and not overwrite guest edits or mutate the template.
The caller must not expose a partially initialized destination as ready.

Verify real native read/admission/publication boundaries in memory and disposable
PostgreSQL, including independent copies, retry/interruption, stale source,
missing/withdrawn evidence, exact source bytes and graph equivalence, aliases,
metadata and cross-World isolation. Inspect exact diff and obtain independent
Bugbot review before merge. Do not use benchmark evaluator databases.
